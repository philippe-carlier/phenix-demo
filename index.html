Tableau de bord - Bureau d'études

Un tableau de bord produit par un programme Python

À partir d’un fichier CSV, le programme contrôle les données, calcule les indicateurs budgétaires et les retards, puis signale les incohérences entre les déclarations et les échéances. Il exporte les résultats en JSON et génère cette page HTML. Des tests automatisés vérifient plusieurs résultats attendus.
